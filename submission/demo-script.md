# RecruiterAgent demo recording

Aim for 90 seconds. Use synthetic applications or data cleared for public display.

1. Show RecruiterAgent branding and a folder with at least 200 applications.
   Explain the goal: cut through volume while humans curate the review.
2. Open the requisition tab and show the requirements used for comparison.
3. Show the real OpenClaw instance accepting the task. Run analysis through the
   connected product; show its completed report and evidence references. Label
   any pre-recorded output accurately. Do not use preview summaries as model output.
4. Inspect one candidate's evidence and a missing/uncertain requirement. Show
   reviewer feedback in the connected flow and its actual response if available.
   The static preview feedback box cannot demonstrate delivery to OpenClaw.
5. Select candidates, advance/hold/reject, and show that decisions are separate
   from file actions. If demonstrating a move, display and approve the exact plan.
6. End with the MIT repository and install-guide URL.

Keep a separate verification record: OpenClaw version, installed source commit,
task/run timestamps, dataset size, actual completed analysis/report, human
decisions, and redacted usage dry-run result. Never publish credentials or private
applicant details. Upload to YouTube and paste the video ID into `listing.json`.
