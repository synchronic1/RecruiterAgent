RecruiterAgent · MIT source

Cut through application volume.
Keep humans in the review.

Install the source-only skill alongside your existing OpenClaw agent. Python dependencies are downloaded during setup; applicant data and dependency binaries are not bundled.

Prerequisites

Python 3.12 or later, a configured OpenClaw instance, package-registry access, and a local job folder. SQLite must stay on storage-host-local storage.

Build from the public source checkout

Obtain the repository linked on the RecruiterAgent Agent Index listing, then run from its root:

python tools/build_openclaw_package.py --output dist/RecruiterAgent

Make the skill available to OpenClaw

Install the generated directory using your OpenClaw version's local skill installation mechanism, or copy it to a trusted configured skills directory. Confirm the intended agent can see the skill. Install only the clean generated directory.

Install and check the application

Replace {baseDir} with the installed skill directory:

python "{baseDir}/scripts/install.py"
python "{baseDir}/scripts/install.py" --verify-only
python "{baseDir}/scripts/run.py" -- --help

Start a real review workspace

python "{baseDir}/scripts/run.py" -- setup --folder <job-folder> --job <job-description.txt> --json
python "{baseDir}/scripts/run.py" -- status --instance <returned-instance-id> --json
python "{baseDir}/scripts/run.py" -- start --instance <returned-instance-id>

Follow the helper's returned connection and session instructions. Configure the restricted OpenClaw analysis route using the packaged operational documentation. Never put Gateway credentials in a page.

Try a synthetic design preview

python "{baseDir}/scripts/install.py" --demo

Serve only the generated application/docs/review-artifacts directory on loopback. The preview has 200 synthetic candidates; changes stay in the tab and its feedback is not sent to OpenClaw.

Human curation

Humans approve criteria and review evidence. Advance, hold, and reject are reviewer decisions. File moves require approval of the exact plan; no automatic rejection or permanent deletion occurs.

See references/install.md and the packaged installation and local-operation guides for details. OpenClaw compatibility and live inference must be verified on your own instance.
