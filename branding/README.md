# RecruiterAgent / Fold

The folded R is the master symbol. Its open center and coral point represent a clear view of the evidence; the person using the review workspace remains responsible for decisions.

## Files

- `recruiteragent-fold-icon.svg`: editable vector master for the app icon and avatar.
- `recruiteragent-fold-icon-{180,192,512,1024}.png`: raster exports, in pixels. The 512 px file also works as a social avatar.
- `recruiteragent-fold-favicon.svg`: simplified small-size mark.
- `recruiteragent-fold-favicon-{16,32}.png`: browser favicon exports, in pixels.
- `recruiteragent-fold-logo-{light,dark}.svg`: full horizontal logos with subtitle.
- `recruiteragent-fold-logo-compact-{light,dark}.svg`: horizontal logos for narrow headers, without subtitle.
- `recruiteragent-fold-logo-{light,dark}.png`: 1400 px wide transparent raster exports.
- `recruiteragent-fold-preview.png`: visual handoff preview.

## Use

Use the light logo on white or pale backgrounds and the dark logo on deep teal or similarly dark backgrounds. Use the compact logo when the full logo would appear narrower than about 340 px. Use the simplified favicon at 32 px and below. Keep clear space around the icon equal to at least one eighth of its width, and preserve its square proportions.

The SVG files are the source artwork. The PNG files are exports. The wordmark uses a Segoe UI / Arial fallback stack; use the PNG lockup when identical typography across computers is required.
